# 遇到问题，从这里开始

先找到问题发生的环节。付款或交付异常优先核对已有记录，不要为了验证状态重复下单或付款。

| 你遇到的问题 | 先看哪一页 |
| --- | --- |
| 无法注册、登录或进入某个中心 | [账户与安全](/zh/getting-started/account/)和[平台与角色](/zh/getting-started/) |
| GitHub 绑定或解绑失败 | [第三方账号连接](/zh/getting-started/connections/) |
| 充值未到账、余额不一致 | [账户充值](/zh/currency/topup/)和[钱包记录](/zh/currency/wallet/) |
| 无法购买、订单取消或付款后没交付 | [购买商品](/zh/shopping/)和[订单状态](/zh/shopping/orders/) |
| 商户商品、收款或收入不一致 | [商品配置](/zh/merchant/products/)和[商户对账](/zh/merchant/orders/) |
| OAuth 失败、接口报错或金额格式不对 | [接入排错](/zh/developer/troubleshooting/)和[数据格式](/zh/developer/data-formats/) |
| 通知没收到、需要联系支持 | [通知与问题反馈](/zh/getting-started/notifications/) |

常见的直接解答集中在[常见问题](/zh/faqs/common/)。反馈仍未解决的问题时，提供发生时间、页面、相关业务编号和脱敏截图，便于定位。
