# 购买商品

商城提供当前可以浏览的商品。下单前请确认商品用途、交付方式与购买提示；有疑问时先联系商户。

## 从商品详情到下单

1. 在“商城”搜索商品，打开详情。
2. 阅读商品说明和购买提示，检查库存、单次限购数量。
3. 选择数量，填写商品要求的附加信息。
4. 选择可用支付方式，查看最新报价。
5. 核对商品总额、优惠、手续费和实际支付金额，再提交一次订单。
6. 进入订单详情付款，并保留订单号。

附加输入可能是交付所需的账号或业务标识，必填项为空会阻止下单。不要在普通附加输入中填写平台登录密码或支付密码。

## 价格和报价

划线价用于展示参考价格，实际售价及批量优惠参与当前购买报价。数量或支付方式变化后，应重新核对报价。

商品币种、支付币种和钱包 TDC 是不同概念。最终应付金额以订单保存的支付报价为准；不要把不同币种的数字直接相加。参阅[金额与手续费](/zh/currency/handling_charge/)。

## 为什么无法下单

| 页面现象 | 检查内容 |
| --- | --- |
| 库存不足 | 刷新商品，减少数量或联系商户；其他待付款订单可能占用库存 |
| 超过限购 | 按商品单次上限调整数量 |
| 提示补充信息 | 检查标为必填的附加输入 |
| 没有支付方式或报价失败 | 商品渠道设置、渠道启用状态、币种与汇率均会影响可用性 |
| 商品不可用 | 商品可能已经下架或发生配置变化 |
| 商户检查未通过 | 根据提示检查业务条件，必要时向商户提供商品编号 |

支付方式暂时不可用时，不要向页面外提供的账号自行转账来代替订单流程。

## 下单后页面中断

先去“我的订单”查找刚才创建的订单，再决定是否重试。关闭标签页不会自动取消订单。已经付款的订单应查看交付状态，不能因为没有跳转成功就再买一次。
