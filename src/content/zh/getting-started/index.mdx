# 平台与角色

三狗云服务是一个自建商品流通与匿名交易平台。普通用户可以管理账户、持有 TDC、充值、浏览商品并创建订单；经营与开放平台能力通过邀请和审核逐步开通。

## 三类使用身份

| 身份 | 主要能力 | 如何获得 |
| --- | --- | --- |
| 用户 | 账户、钱包、充值、商城、订单 | 注册后获得 |
| 商户 | 店铺资料、商品、订单、平台渠道结算 | 获得商户邀请并提交申请，平台审核通过后分配商户角色 |
| 开发者 | OAuth 客户端、用户授权、OpenAPI | 获得开发者邀请并提交申请，平台审核通过后分配开发者权限 |

一个账户可以同时具有多种角色。管理员身份只代表管理权限，并不自动等于商户或开发者身份。

## 为什么看不到入口

商户中心和开发者中心不是固定菜单。平台会按账户权限下发可见路由：

1. 未受邀请时，不显示对应申请入口。
2. 收到邀请后，申请入口出现在头像菜单或个人区域。
3. 提交后仍可进入申请页查看审核进度。
4. 审核通过后，申请入口消失，左侧菜单出现对应中心。
5. 驳回后可以查看原因、修改资料并重新提交。

权限刚发生变化时，重新登录或刷新页面可获取最新菜单。若仍未出现，请联系平台支持核对账户状态。

## 当前边界

- 每个账户最多拥有一个 OAuth 客户端。
- 交易类 OAuth Scope 必须绑定该账户自己已启用的商户。
- 商户申请采用简化的平台审核流程。
