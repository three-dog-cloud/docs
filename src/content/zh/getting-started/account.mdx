# 账户与安全

账户用于保存订单、钱包和角色权限。操作前先确认当前登录的账户，尤其是在同一台设备上切换买家、商户或管理员时。

## 注册与登录

1. 打开[登录页](https://tdcloud.cc/login)。
2. 使用当前账户凭据登录；如果页面提供 GitHub 登录，也可以使用已配置的第三方登录方式。
3. 需要新账户时，使用页面提供的注册入口。注册是否开放由平台配置决定。
4. 登录后进入“个人中心”，核对用户名和用户编号。

GitHub 登录入口是否出现取决于平台配置。绑定已有平台账户的操作见[第三方账号连接](/zh/getting-started/connections/)。

## 修改资料

在“个人中心”修改页面允许编辑的资料，保存后重新检查显示结果。用户编号用于定位账户，不会因为修改显示名称就成为另一个账户。

联系支持处理账户问题时可以提供用户编号；不要提供密码、登录令牌或完整支付凭据。

## 修改密码

在“系统设置 → 账户安全”填写当前密码、新密码和确认密码，然后提交。页面会检查必填项、两次输入是否一致，以及新旧密码是否相同。

忘记当前密码时不能通过这个表单直接重置。请使用登录页实际提供的恢复方式，或联系平台支持。不要在工单中填写旧密码来“证明身份”。

## 角色与访问权限

普通用户、商户和开发者能力可以属于同一个账户，但商户或开发者申请需要对应邀请。审核通过后，平台才会下发相应中心入口。

如果页面显示无权访问，先核对账户、邀请和审核状态，再刷新页面或重新登录。修改浏览器地址无法获得角色权限。参阅[平台与角色](/zh/getting-started/)。

## 离开共享设备

使用“系统设置”或个人菜单退出登录。若怀疑密码泄露，及时更换密码；若泄露的是开发者 Client Secret，则到开发者中心[轮换 Secret](/zh/developer/oauth-client/)，两者不是同一项凭据。
