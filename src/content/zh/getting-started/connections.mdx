# 第三方账号连接

左下角头像菜单的“第三方连接”打开[账号连接页面](https://tdcloud.cc/dashboard/connections)，用于管理 GitHub 等外部账号的绑定关系。

## 绑定 GitHub

1. 先登录希望保留订单和钱包的那个平台账户。
2. 打开“第三方连接”，找到 GitHub。
3. 点击绑定，前往 GitHub 完成授权。
4. 回到平台后，确认连接状态和绑定账号名称。

必须以返回后的实际连接状态为准，不能仅凭浏览器地址中的成功参数判断绑定完成。

## 解绑

在对应连接卡片选择解绑并确认，操作完成后检查是否显示未绑定。解绑前应确认自己仍有可用的平台登录方式，避免失去常用的登录入口。

页面只展示平台已开放的连接类型；未开放的类型不会显示。GitHub 绑定成功后，可以在登录页使用该 GitHub 账号登录已有平台账户。

## 绑定账号和授权应用有什么区别

| 场景 | 作用 |
| --- | --- |
| 把 GitHub 绑定到平台账户 | 让平台识别外部账号与当前账户的关联 |
| 在第三方应用中使用三狗云服务登录 | 通过 OAuth 允许那个应用获取你同意的身份或业务权限 |

这里的解绑操作管理的是外部账号连接，不能当作撤销某个第三方 OAuth 应用权限的操作。当前公开用户页面没有提供独立的 OAuth 授权撤销列表；如需处理异常授权，请联系平台支持。

## 绑定不成功时

核对当前平台账户、GitHub 上登录的账号以及平台是否启用了 GitHub 接入。关闭失败页面后回到第三方连接页刷新状态，再决定是否重新发起；不要反复创建新平台账户来尝试绑定。
