# 通知与问题反馈

“消息通知”保存平台发给当前账户的站内消息。消息是了解事件的入口，订单或钱包的最终结果应到对应业务页面核对。

## 阅读与管理通知

进入“消息通知”可以查看全部消息或只看未读，打开消息详情、标为已读、全部已读或删除消息。刷新页面不会清空已保存的站内消息。

删除通知只处理消息本身，不会取消订单、撤回申请或删除钱包流水。

## 设置通知偏好

打开“系统设置 → 通知设置”，按事件和渠道调整偏好。当前页面区分站内信与邮件；标为强制的安全类通知不能关闭。

偏好开关决定是否接收可选通知，不保证邮件一定送达。渠道是否启用、账户接收信息及投递情况都会影响最终结果。

## 没收到通知怎么办

1. 确认当前账户和“只看未读”筛选条件。
2. 查看通知偏好，检查是否关闭了对应事件或渠道。
3. 直接打开订单、充值记录或申请记录确认状态。
4. 邮件未收到时检查垃圾邮件；业务状态仍不确定时联系支持。

不要因为没有通知就重复付款或重新提交一笔已存在的订单。

## 提交一个可定位的问题

通过平台实际提供的支持入口联系工作人员。商品使用和交付问题，也可以使用商户公开的联系方式。

建议附上：

- 出错页面与操作步骤；
- 大致发生时间和时区；
- 用户编号，以及相关订单号、充值记录号或申请编号；
- 页面显示的状态、币种和金额；
- 已遮盖敏感信息的错误截图。

不要发送密码、Access Token、Refresh Token、Client Secret、完整兑换码或银行卡资料。遇到“渠道已扣款但平台未更新”，保留支付凭证并说明对应订单，先核对，避免再次支付。
