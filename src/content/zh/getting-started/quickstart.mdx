# 第一次使用

从[用户中心](https://tdcloud.cc/dashboard)登录后，可以按下面的顺序完成第一次购买。商户和开发者可在完成账户准备后转到各自指南。

## 1. 准备账户

开放注册时，登录页会显示注册入口；入口未开放时，请联系平台支持了解账户开通方式。不要把“没有注册按钮”当作页面故障。

登录后进入“个人中心”核对当前账户，再到“系统设置”检查密码和通知偏好。详细操作见[账户与安全](/zh/getting-started/account/)。

## 2. 找到要购买的商品

进入“商城”，打开商品详情，阅读用途、购买提示、价格、库存和单次限购数量。有附加输入时，先确认商户需要的交付信息，再填写。

商品计价币种和最终支付币种可能不同。选择支付方式后，以确认区域展示的实际支付金额为准。

## 3. 准备付款

- 使用 TDC：先检查“我的钱包”中的可用余额；不足时可从[在线充值](/zh/currency/topup/)购买 TDC。
- 使用在线支付：选择商品支持且当前启用的渠道，核对报价后继续。
- 没有可用渠道：查看[购买商品](/zh/shopping/)中的排查说明。

充值和购买是两笔不同业务：充值成功只增加钱包余额，不会自动完成商品订单。

## 4. 完成订单并核对

提交一次订单后保留订单号。在“我的订单”里打开该订单完成付款，并查看付款状态和交付进度。页面回跳、弹出成功提示或关闭支付窗口，都不能单独证明商品已经交付。

状态含义见[订单、付款与交付](/zh/shopping/orders/)；余额变化见[钱包与交易记录](/zh/currency/wallet/)。
