# 商户入驻与经营

商户中心用于维护自己的店铺、商品和订单。一个普通账户需要先获得商户邀请、提交申请并通过审核，才会获得经营入口。

## 入驻前准备什么

| 资料 | 填写建议 |
| --- | --- |
| 店铺名称 | 必填，明确说明对外使用的店铺名称 |
| 经营范围 | 必填，说明出售的商品或服务类别 |
| Logo 地址 | 可选，使用可访问的图片地址 |
| 一句话简介、店铺介绍 | 说明商品用途、交付和支持方式 |
| 官网、公开联系方式 | 可选，填写愿意对外展示的联系方式 |

店铺资料会用于公开展示。不要把内部管理地址、支付密钥或私人凭据填进介绍和联系方式。

## 申请与审核

1. 获得邀请后，从个人菜单进入“商户入驻申请”。
2. 填写店铺资料并提交。
3. 在申请页查看审核结果；待审核时不能经营商品。
4. 被驳回时阅读原因，修改后重新提交。
5. 审核通过且商户启用后，从“商户中心”管理店铺。

申请记录和商户当前状态分别反映审核历史与经营资格。已经审核通过的商户仍可能被停用；看到过去的通过记录不代表当前一定可经营。

## 已开通店铺的资料变更

修改店铺名称、经营范围、官网地址或 Logo 地址时，需要再次提交平台审核，删除官网或 Logo 同样需要审核。简介、店铺介绍和公开联系方式可以直接保存。

- 提交后可在商户中心的“申请与审核记录”查看变更前后资料、审核状态和平台意见。
- 审核期间对外继续展示原资料，商户经营资格保持不变。名称、经营范围、官网和 Logo 暂不可再次修改，其他资料仍可更新。
- 审核通过后，申请中的身份资料替换原资料；驳回则保留原资料，可修改后重新提交。
- 资料变更审核与商户启停分别管理。通过资料审核不会自动恢复被停用的商户。

## 开始经营的顺序

1. 核对店铺公开资料。
2. [配置商品](/zh/merchant/products/)，先检查价格、供货方式、购买要求和渠道；本地卡密可直接从[库存中心](/zh/merchant/inventory/)新建。
3. 阅读[支付与结算](/zh/merchant/payments/)，明确买家实付与商户收入的区别。
4. 从买家视角检查商品详情、下单和交付信息。
5. 使用[商户订单与对账](/zh/merchant/orders/)核对订单及钱包入账。

若要让自建应用读取商品或替用户下单，还需要独立的[开发者申请](/zh/developer/quickstart/)。商户身份不会自动生成 OAuth 客户端。

## 当前开放范围

已提供商户资料、商品管理、独立卡密库存、商户订单与平台渠道结算。库存中心只对已审核并启用的商户开放。商户自有 Stripe 渠道需要平台费率、签名 Webhook 与手续费资金条件，见 [支付与结算](/zh/merchant/payments/)。外部业务订单可使用 [通用商户收款](/zh/developer/merchant-payments/)。钱包余额不代表页面已提供提现、银行卡结算或自助退款能力。
