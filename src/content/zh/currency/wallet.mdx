# 钱包、兑换码与交易记录

“我的钱包”展示 TDC 余额；“交易记录”解释余额为什么变化；“充值记录”追踪外部支付购买 TDC 的过程。

## 可用余额与冻结金额

可用余额是当前可用于消费的金额。冻结金额是被业务占用、暂时不能使用的部分，不能当作可再次消费的余额，也不等于已经完成扣款。

付款前核对可用余额是否覆盖订单实付金额，包括适用的手续费。付款后可以刷新钱包，并到交易记录查找该订单对应的扣款。

## 使用兑换码

如果持有平台提供的有效兑换码：

1. 打开“我的钱包”的兑换码区域。
2. 输入兑换码并提交一次。
3. 成功后刷新余额，检查对应交易记录。
4. 提示无效、已使用或不可用时，核对输入并联系发放方。

兑换码不是通用优惠券，也不会直接支付已有商品订单。不要把完整兑换码公开到截图、聊天群或问题反馈中。

## 区分三种记录

| 记录 | 回答的问题 |
| --- | --- |
| 充值记录 | 哪笔外部充值在等待支付、成功或关闭？ |
| 商品订单 | 买了什么，是否付款，交付到了哪一步？ |
| 钱包交易记录 | 哪次入账或扣款改变了 TDC 余额？ |

同一次业务可能同时产生订单和钱包流水；这是关联记录，不代表重复收费。商户销售收入也在商户所属账户的钱包和流水中核对。

## 金额对不上时

先确认账户、币种、筛选时间和业务编号。外部渠道支付金额可能包含手续费，到账 TDC 使用本次充值或订单保存的换算结果，不能直接比较两个数字是否相同。

充值页回跳成功但余额未变时，查看充值记录的确认状态。订单显示已付款但交付未完成时，查看[订单状态](/zh/shopping/orders/)，不要再次充值或付款来“刷新状态”。

当前公开页面没有完整的提现、用户间转账或自助退款入口；不要把余额数字或汇率行情当作这些能力已经开放。
