# 账户充值

账户充值用于通过外部支付渠道购买 TDC。页面会在付款前展示完整的费用与到账信息。

## 充值流程

1. 打开“在线充值”，选择可用支付渠道。
2. 选择预设金额或输入自定义金额。
3. 核对充值金额、手续费、实际支付金额和预计到账 TDC。
4. 发起支付并在支付页面完成付款。
5. 支付确认后，在钱包或充值记录中查看到账结果。

页面会提示当前渠道支持的金额范围。最终可选渠道、币种和费用以充值页面实时展示为准。

## 页面字段

| 页面字段 | 含义 |
| --- | --- |
| 充值金额 | 用于购买 TDC 的金额 |
| 手续费 | 本次充值需要额外支付的费用 |
| 实际支付 | 充值金额与手续费之和 |
| 到账 TDC | 支付成功后预计记入钱包的 TDC |

## 暂时无法充值

如果渠道不可用、金额不符合要求，或页面暂时无法显示预计到账 TDC，充值按钮会保持不可用。请选择其他可用渠道、调整金额或稍后重试。

不要在未显示预计到账数量时离开平台自行付款；每次充值都应从当前充值页面发起。

## 付款后核对

充值是购买 TDC，不会自动完成商品订单。支付窗口关闭或返回平台后，到“充值记录”确认付款状态，再到钱包核对到账和对应流水。

若渠道已经扣款但记录仍未确认，保留充值记录号与支付凭证，先联系平台核对，不要直接重复支付。兑换码和不同记录的关系见[钱包与交易记录](/zh/currency/wallet/)。
