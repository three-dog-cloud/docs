# 金额与手续费

充值、商品订单和开放收款都可能包含手续费。确认付款前，请分别核对交易金额、手续费和实际支付金额。

## 充值费用

> **实际支付金额 = 充值金额 + 手续费**

手续费通常在充值金额之外收取，不会从页面显示的预计到账 TDC 中扣除。例如页面显示：

| 项目 | 金额或说明 |
| --- | ---: |
| 充值金额 | `10.00 USD` |
| 手续费 | `4.56 USD` |
| **实际支付** | **`14.56 USD`** |
| 预计到账 | 以确认页显示为准 |

## 商品订单费用

商品订单的付款确认页会分别展示：

- 商品小计；
- 买家手续费；
- 最终支付金额；
- 支付币种。

如果商品标价币种与支付币种不同，付款确认页会展示换算后的应付金额。请以该页面最后确认的金额为准。

## 商户到账金额

使用平台渠道收款时，买家手续费加到实付金额中，商户手续费从结算款中扣除；扣费后的净额以 TDC 入账。买家手续费不计入商户收入。商户自有渠道由商户直接收款，不再重复记入 TDC 销售款。

金额和费用按所选付款币种四舍五入，正手续费至少达到该方式可收取的最小金额；确认页展示的实付金额用于发起渠道扣款。无法正确处理的币种不会作为可用方式开放。

## 退款与重复通知

完整退款按原实付核对，并使用订单保存的汇率处理 TDC 账务。手续费不返还，因此退款可能超出净结算款，差额按平台规则从担保金等资金承担。部分退款尚不支持自动处理，不能按整单退款记账。

平台核验收款后才确认支付；页面返回或点击成功按钮不能作为到账依据。重复通知不会重复入账，已退款订单收到原支付通知也不会再次结算。

## 查询历史金额

充值记录和订单详情会保留交易发生时确认的金额与币种。遇到支付结果未更新或金额存疑时，请不要重复付款，可凭订单号联系平台支持。
