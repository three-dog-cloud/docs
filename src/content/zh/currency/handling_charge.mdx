# 金额与手续费

充值和商品订单都可能包含手续费。确认付款前，请分别核对交易金额、手续费和实际支付金额。

## 充值费用

> **实际支付金额 = 充值金额 + 手续费**

手续费通常在充值金额之外收取，不会从页面显示的预计到账 TDC 中扣除。例如页面显示：

| 项目 | 金额或说明 |
| --- | ---: |
| 充值金额 | `10.00 USD` |
| 手续费 | `4.56 USD` |
| **实际支付** | **`14.56 USD`** |
| 预计到账 | 以确认页显示为准 |

## 商品订单费用

商品订单的付款确认页会分别展示：

- 商品小计；
- 买家手续费；
- 最终支付金额；
- 支付币种。

如果商品标价币种与支付币种不同，付款确认页会展示换算后的应付金额。请以该页面最后确认的金额为准。

## 查询历史金额

充值记录和订单详情会保留交易发生时确认的金额与币种。遇到支付结果未更新或金额存疑时，请不要重复付款，可凭订单号联系平台支持。
