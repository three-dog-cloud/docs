# TDC 余额

TDC 是三狗云服务中的账户余额单位，可用于商城购物、订单支付和平台内结算。它不是公开区块链上的代币。

## 如何获得 TDC

你可以通过“在线充值”购买 TDC。选择支付渠道和充值金额后，确认区域会在付款前清楚展示：

- 本次充值金额；
- 手续费；
- 实际支付金额；
- 预计到账的 TDC 数量。

请以付款确认页展示的金额为准。完成支付并经支付渠道确认后，TDC 会记入你的平台钱包。

## 到账数量

不同支付渠道可能使用不同币种，页面会自动给出本次可获得的 TDC 数量，不需要自行换算。

如果当前渠道暂时无法提供到账数量，充值按钮会不可用。你可以选择其他可用渠道或稍后重试。

## 金额显示

支付金额会按对应币种显示，TDC 余额最多显示八位小数。订单记录会保留交易发生时确认的金额，不会因之后的价格变化而改变。

有关手续费和实际支付金额，请参阅[金额与手续费](/zh/currency/handling_charge/)。
