## 接口范围

用户身份能力无需商户身份。店铺与交易接口只能访问客户端绑定商户的资源；订单和支付必须使用用户授权令牌，同时校验用户与商户归属。

API Base URL 和各 OAuth 服务地址由平台按客户端分配，在开发者中心的“服务地址”中查看。文档中的接口路径与地址占位符说明见 [接入概览](/zh/developer/quickstart/)。账户管理、商户后台与平台内部授权确认接口不属于第三方 OpenAPI。
