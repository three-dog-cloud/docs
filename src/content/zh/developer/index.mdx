# 开发者平台

开发者平台允许第三方站点使用三狗云服务的统一 OAuth 授权、用户身份和交易能力。当前每个账户最多申请一个 OAuth 客户端，开发者入口采用邀请和审核机制。

## 开通流程

1. 获得开发者邀请。
2. 从个人菜单进入开发者申请页。
3. 填写应用资料、回调地址和所需 Scope。
4. 提交审核，并通过申请入口查看进度。
5. 审核通过后，开发者中心会出现在业务菜单中。
