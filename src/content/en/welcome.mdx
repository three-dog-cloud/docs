## Suggested reading

- Users can start with [Your first visit](/en/getting-started/quickstart/) and consult [order guidance](/en/shopping/orders/) for payment or delivery issues.
- Merchants can start with [onboarding](/en/merchant/), then review [product configuration](/en/merchant/products/) and [revenue settlement](/en/merchant/payments/).
- Developers can start with the [quickstart](/en/developer/quickstart/), integrate [products and payments](/en/developer/commerce/) as needed, and check [amount formats](/en/developer/data-formats/).

Credited amounts, fees, and order totals are confirmed on screen before submission.
