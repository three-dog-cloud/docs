# Developer Platform

The developer platform lets third-party sites use TD Cloud OAuth, identity, and transaction capabilities. Each account may currently apply for one OAuth client. Access is invitation-based and reviewed before approval.

## Enablement flow

1. Receive a developer invitation.
2. Open the developer application from the profile menu.
3. Enter the application details, redirect URIs, and required scopes.
4. Submit the application and use the same entry to track review progress.
5. Developer Center appears in the business menu after approval.
