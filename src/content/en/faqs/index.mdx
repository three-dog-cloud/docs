# Find help by task

Identify where the problem occurred. For payment or delivery issues, check existing records before placing an order or paying again to test the status.

| Problem | Start here |
| --- | --- |
| Registration, sign-in or access to a center | [Account and security](/en/getting-started/account/) and [roles](/en/getting-started/) |
| GitHub connection or disconnection | [Connected accounts](/en/getting-started/connections/) |
| Missing top-up credit or balance mismatch | [Top-ups](/en/currency/topup/) and [wallet records](/en/currency/wallet/) |
| Ordering, cancellation or missing delivery | [Buying products](/en/shopping/) and [order statuses](/en/shopping/orders/) |
| Merchant products, payments or revenue | [Product configuration](/en/merchant/products/) and [reconciliation](/en/merchant/orders/) |
| OAuth errors, API failures or amount formats | [Troubleshooting](/en/developer/troubleshooting/) and [data formats](/en/developer/data-formats/) |
| Missing notifications or contacting support | [Notifications and support](/en/getting-started/notifications/) |

Read [Common questions](/en/faqs/common/) for direct answers. When reporting an unresolved issue, provide the time, page, relevant business identifier and a sanitized screenshot.
